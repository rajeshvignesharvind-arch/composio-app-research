We researched 100 apps for agent-toolkit buildability. Here is what the pattern says.

86% are self-serve, 58 can be built today, 5 need outreach or a different route. An agent did the research with evidence quotes for every answer; a different model re-checked it, and a 20-app gold set drafted from vendor docs (not human-confirmed) scored it: accuracy rose from 40.6% in pass 1 to 46.9% after the verification loops, on the eight fields a reviewer acts on. That is still low; read the verification section before relying on any single cell.

Patterns

Computed by code over the final records; nothing below is a model's impression.

  • 86% of apps are self-serve (a developer can get working credentials free or on a trial); 8% need an admin, a sales call or a partner gate.
  • OAuth2 is the primary auth for 48 apps; static API keys / bearer tokens for 40. 55 apps offer more than one method.
  • Most common blocker: other (23 apps). Salesforce, Pipedrive, Copper, Front, Twilio, Zoho Cliq…
  • 58 apps are ready to build today (self-serve credentials + moderate/broad documented API); 5 are blocked by access, and need outreach or a different path.
  • 82 apps already have an official MCP server, 16 only a community one, 2 none found: a quick win is wrapping what exists.
  • Most self-serve category: Developer Infra and Data (100%). Most gated: Support and Helpdesk (60% self-serve).

The agent

A Python pipeline, free-tier only. Every field must carry a source and a verbatim quote, or it is marked unknown.

1 Seed
apps.yaml, hint URL pins identity
→
2 Discover
Tavily: 3 vendor-domain searches + 1 open MCP search
→
3 Fetch
Firecrawl, Jina Reader fallback, cached
→
4 Extract
Groq LLM, strict JSON + quotes
→
5 Ground
code checks each quote is on the page, else unknown
→
6 Derive
buildability + blocker from a written rule
→
7 Critic
other Groq model: live re-fetch, judge, adversarial search
→
8 Re-research
flagged fields redo, max 2 rounds
→
9 Human
gold-set check + needs_human fields

Why two Groq models

Both models run on Groq's free tier, because that was the budget. To keep the check independent, each app is extracted by one model (gpt-oss or qwen, alternating) and re-checked by the other. This is weaker independence than a different vendor would give; the gold set is what measures actual accuracy.

Where a human was needed

  • Writing the 20-app gold answers from primary docs (done by the builder; a human confirmation pass was prepared as a checklist but not performed).
  • Ambiguous or obscure identities: fanbasis, iPayX, Paygent Connect, Waterfall.io, Sherlock, higgsfield.
  • Docs behind a login or sales gate (DealCloud, Gladly, PitchBook, fanbasis docs), where the gate itself is the finding.
  • Fields still flagged after 2 critic rounds are listed in what defeated it.

Run stats

100/100 apps completed; 598 pages fetched; total cost $0 (free tiers). Groq's 8k tokens/min and 200k tokens/day caps set the speed, not the code.

Verification

A 20-app gold set (2 per category: one well-known, one obscure/gated) was drafted by the builder from live vendor docs, frozen before pass 2, and used to score every pass on the same apps. It was not independently human-confirmed (the human spot-check was skipped), so these numbers measure agreement with docs-sourced answers written by the same person who built the agent, not an external audit.

Gold set n=20 (160 field checks): roughly ±8 points of noise. Not human-confirmed. The gold was revised after pass 2 in three places (existing_mcp for systeme.io, MrScraper, higgsfield, once the detector surfaced vendor MCP pages); 'frozen gold v1' shows scores on the unrevised answers. 13 of 85 remaining misses are 'unknown' (the agent could not ground an answer), the rest are wrong values or taxonomy judgement calls; the agent is biased toward 'self-serve' on gated apps. buildability and main_blocker are derived by rule from the other fields, so their errors compound.

Run it yourself

git clone https://github.com/rajeshvignesharvind-arch/composio-app-research
cd composio-app-research && pip install -r requirements.txt && cp .env.example .env   # add GROQ / TAVILY / FIRECRAWL keys
python -m agent.run --app "Pumble"      # one app end to end, about a minute
python -m agent.run --all               # all 100, resumable
python -m agent.build_site              # rebuild this page
